## สิ่งที่ได้จาก Day 01 (ทบทวนเร็ว)

1. **Positive class = actual defect.** FR หารด้วยชิ้นดีทั้งหมด (894), FA หารด้วยชิ้นเสียทั้งหมด (110)
   FR/FA ไม่ขึ้นกับสัดส่วนของเสีย แต่ precision ขึ้น
2. **Constraint-first:** ล็อก FA ตาม spec → หา threshold ที่ FR ต่ำสุด **บน val** → test ใช้ครั้งเดียว (กัน optimistic bias)
3. **Rule of three:** (1−p)^n = 0.05 → n·ln(1−p) = ln 0.05 ≈ −3 → ln(1−p) ≈ −p → p ≈ 3/n
   - 0/110 → ขอบบน 2.73% → test KSDD2 **ยืนยัน Req-1 (0.5%) ไม่ได้**
   - ต้องการ 0.5% → ภาพเสีย ≥ 600 (หลุด 0) หรือ ≥ 947 (หลุด 1, Clopper–Pearson)
   - FA = 0% พิสูจน์ไม่ได้ด้วย n จำกัด
4. **FR ยืนยันง่ายกว่า** เพราะ n ใหญ่: reject ผิดได้ถึง 33/894 (≈ 3.7%) ขอบบนยัง 4.9% ≤ 5%
5. **Latency:** สายพานเดินต่อเนื่อง → p99 (tail) / สายพานหยุดรอ → mean หรือ throughput
6. **หลายภาพต่อชิ้น + OR rule:** FR ต่อชิ้นขึ้น, FA ต่อชิ้นลง, แต่การ**ยืนยัน**ทำยากขึ้นเพราะจำนวนชิ้นน้อยกว่าจำนวนภาพ

<details>
<summary>ตัวอย่างตัวเลข OR rule (ลองคิดเองก่อนเปิด)</summary>

3 ภาพต่อชิ้น, ภาพเป็นอิสระต่อกัน, reject ชิ้นถ้าภาพใดภาพหนึ่งถูกทำนายว่าเสีย

- **ชิ้นดี**, FR ต่อภาพ 5% → ชิ้นรอดเมื่อทั้ง 3 ภาพผ่าน = 0.95³ = 0.857
  → **FR ต่อชิ้น = 1 − 0.857 ≈ 14.3%** (สูงกว่า 5% เกือบ 3 เท่า)
- **ชิ้นเสีย** ที่ตำหนิเห็นใน 2 ภาพ, miss ต่อภาพ 10% → ชิ้นหลุดเมื่อ**พลาดทั้ง 2 ภาพ** = 0.1² →
  **FA ต่อชิ้น = 1%** (ต่ำกว่า 10%)
- ภาพที่สามของชิ้นเสีย (ไม่เห็นตำหนิ) ก็อาจถูก reject ผิดได้ ซึ่งยิ่งทำให้ FA ต่ำลงอีกนิด — ตัวเลขข้างบนจึงเป็นค่าที่ระมัดระวัง

</details>
